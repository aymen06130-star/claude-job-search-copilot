# Contributing

Thanks for considering a contribution.

1. Keep the Skill focused, concise, and privacy-first.
2. Add detailed guidance to an on-demand reference file instead of expanding the always-loaded frontmatter.
3. Keep the Python helper offline and dependency-free.
4. Do not add real CVs, personal data, credentials, or private application artefacts.
5. Run `python -m unittest discover -s tests -v` before submitting a change.
6. Never represent a heuristic match score as a hiring probability or guarantee.
