# CV privacy checklist

A CV can contain direct identifiers and sensitive contextual information. Handle it as user-controlled private data.

- Process the CV in the current environment only; do not transmit it to a new service for parsing, enrichment, scoring, or storage.
- Search the web using generic role/skill/location terms, not the CV itself.
- Avoid including name, personal email, phone, postal address, date of birth, photo, or identity numbers in generated job-search artefacts unless strictly needed and explicitly requested.
- Do not commit a real CV, candidate profile, cover letter with personal contact details, or job-search export to a public repository.
- Ask before creating or saving a local profile file. Explain where the file will be written.
- Before sharing a tailored application, let the user review it. Never submit it automatically.
- If a user asks to use an external service, explain what data it receives and obtain explicit permission before sending anything.
