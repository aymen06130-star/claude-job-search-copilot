# Search workflow (load on demand)

## 1. Build a compact query plan

Use no more than 3–5 focused searches in the first pass. Mix title synonyms with location and work mode. Search for the role rather than the user's name or CV text. Expand only when the first pass returns too few credible results.

## 2. Verify each listing

Prefer the employer's own careers page. Confirm the listing still appears open where possible. Capture the source URL and any visible posting date, location, work mode, seniority, and stated requirements. If a date is absent, say “date not shown”; do not guess. If the vacancy cannot be opened, label it “not independently verified”.

## 3. Compare against CV evidence

For each major requirement, cite the specific experience, project, credential, or skill evidence in the CV. Separate:
- Direct match.
- Transferable/adjacent evidence.
- Missing requirement.
- Unknown (not stated in CV or vacancy).

Do not interpret absence from the CV as proof the candidate lacks a skill; ask before treating an unknown as a hard gap.

## 4. Prioritize

Rank first by mandatory requirements and practical constraints, then by evidence of relevant experience and preferred skills. A title match alone is not enough. Explain trade-offs in plain language.

## 5. Return a compact shortlist

Default to five listings. Include source URLs, concise reasons, gaps, and the next action. Do not output a giant scraped catalogue. Offer to tailor the CV or cover letter to one selected vacancy.
